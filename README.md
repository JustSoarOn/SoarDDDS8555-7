# SoarDDDS8555-7
SoarDDDS8555-7 — Assignment 7: Clustering Analysis
Overview

This repository contains the complete analysis and report for Assignment 7: Clustering Analysis for the DDS-8555 course.

The project examines clustering and dimensionality-reduction methods for identifying structure in multivariate data. The analysis combines a mathematical examination of the K-means objective with applied hierarchical clustering and K-means analyses using the USArrests and wine chemistry datasets.

The primary objectives are to:

Demonstrate mathematically why the K-means algorithm does not increase its within-cluster sum-of-squares objective during an iteration.

Apply hierarchical clustering to the USArrests dataset using Euclidean distance and complete linkage.

Examine how standardization affects hierarchical clustering results.

Apply Principal Component Analysis (PCA) to a wine chemistry dataset.

Reduce the wine data from 13 original variables to five principal components while retaining at least 80% of the total variance.

Evaluate K-means solutions using inertia and silhouette scores.

Interpret the resulting wine clusters using the original chemical characteristics.

Compare K-means and hierarchical clustering solutions using the Adjusted Rand Index.

Examine how preprocessing and methodological choices influence clustering results.

Methodology
1. K-means Objective

The conceptual portion of the assignment establishes why the K-means centroid-update and observation-reassignment steps cannot increase the within-cluster sum-of-squares objective.

The analysis demonstrates that:

Updating cluster centroids using the cluster means minimizes the within-cluster sum of squared deviations for fixed assignments.

Reassigning observations to their nearest centroid minimizes each observation's contribution for fixed centroids.

Consequently, each iteration produces a non-increasing objective value.

Because the objective is bounded below by zero, the algorithm converges to a local optimum.

2. Hierarchical Clustering

Hierarchical clustering is performed using:

Euclidean distance

Complete linkage

Original/unscaled variables

Standardized variables

The comparison demonstrates the effect of measurement scale on distance-based clustering.

3. Principal Component Analysis

PCA is applied to the standardized wine variables.

The analysis retains five principal components, which explain:

80.1623% of the total variance.

This reduces the dimensionality from 13 original variables to five orthogonal components while satisfying the assignment requirement to retain at least 80% of the variance.

Euclidean-distance-based clustering can be substantially affected by differences in measurement scale.
